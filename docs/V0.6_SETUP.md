# v0.6 setup

The operations dashboard uses Ant Design 6 for its responsive layout, navigation, forms, feedback, tables, cards, upload controls, and theme tokens. Install dependencies with `npm install` before starting or building the dashboard.

## Prerequisites

- Node.js and npm
- Supabase CLI
- An existing project with migrations through 202607220009_v0_5_users_basic_rbac.sql
- Existing Auth users and at least one active Admin

No service-role key, secret key, or database password is required by either frontend.

## Apply the migration

From the repository root:

    npx supabase login
    npx supabase link --project-ref YOUR_PROJECT_REF
    npx supabase db push --dry-run --linked
    npx supabase db push --linked

Confirm that the dry run lists the expected unapplied migrations before approving the real push. For a database currently at v0.5, these include 202607220010_v0_6_individual_applications.sql, 202607240011_resume_structured_schema_v2.sql, and 202607240012_fix_applier_progress_updates.sql. These migrations are additive and do not delete or seed business data.

For local development with Docker running:

    npx supabase start
    npx supabase db reset
    npm run test:db

## Assign operational roles

Use the existing Admin dashboard:

- APPLIER receives assigned-Application access.
- APPLYING_MANAGER receives all-Application management and a read-only active-Applier directory.
- ADMIN receives all Application and existing user-management access.
- Developer roles receive no Application access unless combined with an operational role.

## Run the applications

Create dashboard/.env.local from dashboard/.env.example, using only the project URL and publishable/anon key. Then:

    npm install
    npm run dev:dashboard
    npm run build:extension

Load extension/dist as an unpacked extension. v0.6 does not change extraction or capture behavior.

## Admin PDF Resume upload

An active Admin sees Upload Resume in dashboard navigation. Choose a text-based PDF smaller than 5 MiB, review the locally extracted fields, and select a primary category if no reliable suggestion was found. Professional Experience is an editable list: add or remove positions, correct the company/title/location/dates, mark current roles, and edit the single multiline achievements-and-responsibilities field for each experience. The Resume row records the Admin Auth user ID as user_id for upload traceability. The PDF is stored privately under that user ID. Apply migration 202607240011_resume_structured_schema_v2.sql before saving schema-version-2 uploads.

Image-only/scanned PDFs are not supported because this milestone does not add OCR or an external extraction service.
