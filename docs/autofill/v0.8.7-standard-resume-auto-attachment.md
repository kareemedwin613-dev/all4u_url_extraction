# v0.8.7 Standard Resume auto-attachment

## User flow

1. Start **Load Resume** from an eligible Application.
2. v0.8.6 securely loads the exact Application Resume into extension memory.
3. Review the tracked job page and select **Attach Resume to Page** in the side panel.
4. The service worker injects the bundled generic upload adapter only into the tracked target tab.
5. The adapter detects a high-confidence standard Resume/CV file input, validates the file against its `accept` list, assigns a `File` through `DataTransfer`, dispatches `input` and `change`, and verifies the filename and size.
6. The side panel reports **Resume Attached**, **Manual Required**, **Unsupported Site**, or a safe failure.

The explicit attachment button preserves the required human-review step. The extension never submits the form.

## Detection

The generic detector considers:

- `input[type="file"]`
- `accept`
- label and wrapping-label text
- `name`, `id`, `aria-label`, `placeholder`, and `title`
- nearby text
- the terms `resume`, `résumé`, `cv`, and `curriculum vitae`

Inputs identified as cover-letter uploads are excluded. Generic or ambiguous file inputs are not automatically populated.

## Validation and verification

- Supported formats: PDF, DOCX, and plain text.
- Maximum size: 5 MiB.
- Extension, MIME type, actual byte count, and input `accept` are validated.
- Attachment uses `DataTransfer` and dispatches bubbling, composed `input` and `change` events.
- Verification checks the input's selected file name and size, with nearby filename text as a fallback for standard upload widgets.

## Manual fallback

If `DataTransfer` is unavailable, the page blocks programmatic assignment, or verification fails, the adapter scrolls to and focuses the detected input. The user is instructed to use the site's native file chooser manually.

## Security

- Resume bytes remain memory-only.
- The transient base64 transport is sent only between extension contexts and is never stored or logged.
- Dynamic injection is limited to the Application session's tracked tab and requires existing Chrome site access.
- No remote executable code is used.
- No automatic submission, ATS-specific behavior, iframe traversal, or Shadow DOM traversal is implemented.

## Database and API impact

No database migration or new API endpoint is required. v0.8.7 builds on the v0.8.6 Resume-access endpoint and memory store.
