# Workday support

Status: implemented for the **My Experience** step and Resume upload. Built against Workday's standard markup and checked in Chrome on a Workday-like test page. Not yet confirmed on a live Workday application, which needs a signed-in account.

Workday (`*.myworkdayjobs.com`, `*.myworkdaysite.com`) was the largest source of unanswered questions: about 56% over a week in October 2026.

## What Autofill does on Workday

| Step | What is filled |
| --- | --- |
| Autofill with Resume | The Resume is attached to Workday's upload, which is hidden behind "Select file". Workday then reads it and pre-fills later steps. |
| My Experience: Work Experience | Job title, company, location, "I currently work here", From and To (MM / YYYY), role description |
| My Experience: Education | School, Degree, Field of Study, From and To years |
| My Experience: Skills | Each Resume skill that Workday's own skills list contains exactly |
| My Experience: Resume/CV | The Resume, as above |
| Other steps | The usual rules: contact details, Application Guide answers, AI-recognized questions |

Workday changes steps without reloading the page, so **click Autofill again on each step**.

## How entries are handled

- **Section empty:** each Resume job or school is added with Workday's **Add** / **Add Another** button and filled in.
- **Entries already present** (usually Workday's own Resume parsing): an entry is matched to a Resume row by company and title (school for education), and only its **empty** fields are filled. Nothing Workday or a person entered is overwritten.
- **Missing Resume rows:** added only when every entry on the page matches a Resume row. If the page holds an entry under a different name, nothing is added, so there are no duplicates.
- **Degree:** matched by level. "Bachelor of Science" chooses "Bachelor's Degree"; "MBA" chooses "Master's Degree".
- **Field of Study:** searched and the closest result picked.
- **Skills:** each one is searched, and only an exact match is picked. A skill not in the employer's list is skipped rather than guessed; the side panel shows the result as "Skills (N from the Resume)".

Only Workday's Add buttons, dropdown buttons and search results are clicked. "Save and Continue", "Submit", "Select file" and other sections' Add buttons (Websites, Certifications) are never touched.

## Not yet covered

- Workday's dropdown questions shown as "Select One" buttons, on the Application Questions and Voluntary Disclosures steps and for State, Country and Phone type on My Information.
- "How Did You Hear About Us?", which is a nested search.

These need a structure snapshot of those steps from a signed-in account (`scripts/autofill/form-structure-snapshot.js`).
