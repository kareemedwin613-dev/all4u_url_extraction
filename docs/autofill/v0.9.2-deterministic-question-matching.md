# v0.9.2 deterministic question matching

This milestone improves Autofill without an AI service.

The extension normalizes labels, accessible names, placeholders, field names, and ATS wrapper labels. Exact and contained Answer Library patterns remain preferred. Conservative token matching handles ordinary wording differences only when the saved/canonical wording has strong coverage.

After one-click Autofill, **Unresolved questions** separates fields that have no matching verified answer from sensitive, legal, attestation, and long-form questions that require manual review. The exact wording can be copied and added to the matching Resume Answer Library entry by an Applying Manager or Admin. Existing bulk Answer Library saving remains the only persistence path; no additional table is introduced.

Safety boundaries remain unchanged:

- Autofill never submits an application.
- Unknown answers are never invented.
- Legal attestations and long-form answers are not filled.
- Only verified Resume metadata and verified Answer Library values are used.
- Resume/application access continues through authenticated backend APIs.
