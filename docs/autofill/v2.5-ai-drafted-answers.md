# AI-drafted answers

Status: implemented (migration v3.164). Builds on [AI question recognition](v2.3-ai-question-recognition.md). Phase 3 of the [phase 2 plan](v2.1-phase-2-llm-plan.md).

## What it does

Some questions ask for the candidate's own words: "Why do you want to work at Acme?", "Describe a project you are proud of". For these, Autofill asks the AI to draft an answer from the Application's Resume (the tailored one when there is one) and the job description, and fills it into the box.

Drafted boxes are marked **AI draft: review** in the side panel and outlined on the page; the outline goes once a person types in the box. As with all Autofill, a person reviews the page before submitting. The AI may give plausible examples, but employers, titles, dates, degrees, schools and certifications must match the Resume.

## Which questions are drafted

| Drafted | Never drafted |
| --- | --- |
| Open-ended questions: "why …", "describe …", "explain …", essays | Questions the rules or AI recognition already answered |
| Unanswered text boxes, unless the AI marked them as needing a standard answer or as a statement | Questions marked **Needs a standard answer** (an Admin adds those on the Application Guide page) |
| One-line inputs the AI marked as open-ended | Sensitive questions (demographics, disability, criminal history …) |
| | Legal statements, certifications, attestations, consents |
| | Cover letter boxes (filled from the Application's own letter) and optional "Anything else / Additional information" boxes |
| | Recovered sessions and Resumes set to review every field first |

At most 8 questions are drafted per page. Text boxes get about 80–150 words, and one-line inputs one sentence; drafts always fit the field's own length limit. The model leaves a question for a person (skip) when it would need information it cannot know, such as references, salary history or ids.

## What is sent and stored

| | Contents |
| --- | --- |
| Sent to the AI provider | The Resume's summary, skills, work history (titles, companies, dates, details), education, certifications; the job's company, title and description (first 8,000 characters); the questions. |
| Never sent | The candidate's name, email, phone, address, LinkedIn, GitHub or portfolio links. They are not loaded, and any that appear inside text are replaced with [email], [phone] or [link] first. |
| Stored | Nothing about the drafts. Usage only: per hour, drafted-answer count, tokens and cost. |

The Resume's *Use profile fields in Autofill* consent applies: without it, nothing is drafted. Drafting uses the **Drafting model** chosen in **Configure** on the Overview, and counts toward the same monthly cap. The Overview shows "N answers drafted" in the AI cost card.

**Recommended before turning it on:** enable *Zero data retention* for your team in the xAI console, because drafting sends Resume and job content. By default xAI keeps API requests for 30 days for abuse monitoring.

## Cost

Each drafting call sends about 3,000–5,000 tokens (Resume plus JD) and returns about 200 tokens per answer. With `grok-4.3` that is about $0.006–0.01 per page with open-ended questions, or under $10 a month at about 1,600 autofilled pages.
