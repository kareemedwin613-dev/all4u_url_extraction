# v0.6 troubleshooting

## Applications is missing

Confirm the profile is active and has APPLIER, APPLYING_MANAGER, or ADMIN. Sign out and back in after role changes so the access context refreshes.

## Creation or assignment fails

The Resume must be active. An assignee must have an active profile and active APPLIER role. One JD/Resume pair can have only one Application.

## Applier cannot update

The Application must currently be assigned to that Auth user. Appliers cannot change assignment, priority, due date, creator, or assigner. Unassignment uses the manager/Admin reassignment action.

## Resume does not open

Resume objects are private. Use Open Resume from an accessible Application. An Applier loses file access after reassignment or unassignment. Signed links expire after 90 seconds.

## RPC is missing

Run npx supabase migration list --linked, then dry-run the database push. Do not compensate by adding a privileged key to the dashboard.
