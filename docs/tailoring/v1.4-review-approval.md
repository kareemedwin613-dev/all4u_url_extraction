# v1.4 human review and content approval

v1.4 adds a manager/admin review queue for v1.3 previews. Reviewers can edit the three permitted tailored sections, save a draft, approve the content, or reject it with a required reason. Every action stores an immutable audit record with the previous and resulting preview.

The protected database operation uses `updated_at` as an optimistic concurrency token. A stale reviewer cannot overwrite a newer review. PostgreSQL revalidates the complete preview, its exact source experience IDs, and its source-evidenced skills even when the RPC is called outside the dashboard.

`APPROVED` means the structured content is ready for a later rendering milestone. It does not mean a file or tailored Resume exists.

## Explicit boundary

This milestone does not create a `TAILORED` Resume row, render DOCX/PDF, write Storage, change `applications.resume_id`, or expose approval actions to Appliers.
